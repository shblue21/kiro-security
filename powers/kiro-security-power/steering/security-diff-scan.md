Start `diff` mode with `analysisProfile: "model"`, truthful model/runtime attestation, and a safe working-tree, commit, or range target. Run one all-six discovery round and semantic merge, then complete the shared model tail. Apply the discovery and tail judgment contract in `deep-security-scan.md`, but stay anchored to the changed behavior. Treat the immutable bounded `diff-context.json` as target evidence: inspect its hunks, deleted lines, rename hints, and snapshot-bound supporting sibling paths. Unchanged supporting files are context or negative controls unless the diff newly reaches them, weakens their shared control, or changes a shared sink/helper. Do not infer caller relationships from a sibling-path hint, cite paths outside the assigned snapshot, or substitute Fast heuristic output.
