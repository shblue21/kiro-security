연결 방식

자동 포함 steering이 보안 워크플로를 제공합니다.

직접 도구 Hook은 각 요청을 Kiro session_id에 결합하고, MCP는 이를 한 번만 소비해 채팅이 소유한 워크스페이스를 보호합니다.
