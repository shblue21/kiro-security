Kiro Chat을 연결할까요?

현재 사용자의 모든 Kiro Chat에 보안 워크플로를 연결합니다.

01관리되는 직접 MCP 런타임 등록
02자동 포함 steering 파일 생성
03채팅 식별 Hook 파일 생성
04Kiro Trust 승인 규칙 추가

Start와 Cancel 도구는 항상 Kiro의 명시적 승인을 요구합니다. 사용자 정의 Agent 설정은 설치하지 않습니다.
